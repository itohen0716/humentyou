# 絲庵 文化譜面帳（新規作成版 v1.3）

既存の文化譜面帳コードを流用せず、0から作り直した最初の段階です。

## 現在実装済み
- トップ画面
- 「＋文化譜を追加」から文化譜JSONを選択
- かな曲名は読みを自動利用
- 漢字を含み読み情報がない場合は、初回だけ「よみ」を入力
- 読みを使った50音順の自動整列
- ［すべて／あ／か／さ／た／な／は／ま／や／ら／わ］絞り込み
- 曲名・よみ検索
- 同名曲の重複時は「更新／キャンセル」
- 譜面帳から削除（元JSONは削除しない）
- ブラウザ localStorage に譜面帳データを保存

## 未実装
- 「譜面を見る」
- 編集連携

未実装ボタンは、現段階では誤動作防止のため無効化しています。

このフォルダの中身をリポジトリ直下へアップロードすれば、`index.html` がトップページになります。

## v0.8 自動演奏連携
- 一覧の［▶ 自動演奏］を有効化。
- 選択した文化譜JSONを `sessionStorage` で一時受け渡し。
- `player.html` が独立公開中の絲庵譜プレーヤーを読み込み、選択曲を自動で読み込ませる。
- プレーヤー本体のコードは文化譜面帳へコピーしていない。
- 絲庵譜プレーヤー本体が更新されれば、譜面帳側は公開中の最新版を読み込む構成。
- ［← 譜面帳へ戻る］を追加。
- 将来の販売・認証機能は未実装。プレーヤーを独立させたまま後付けできる構成。

## v0.9 譜面帳経由モード
- 以前の譜面帳と同じ `shian-scorebook-player-score` を受け渡しキーとして使用。
- ［▶ 自動演奏］から開いた場合、現在公開中の絲庵譜プレーヤーを読み込む。
- プレーヤー本体のGitHubコードは変更しない。
- 譜面帳経由時だけ［絲庵譜を読み込む］をグレーアウト＋disabled。
- 譜面帳経由時だけ［← 文化譜面帳へ戻る］をプレーヤー画面上部に表示。
- 選択した文化譜を自動読み込み。
- プレーヤー単独利用には影響しない。

## v1.1 修正
- ［GO：譜面を見る］後に「文化譜を表示できませんでした。」となる不具合を修正。
- 原因：閲覧ブリッジの文化譜アプリ接続先を、存在しない `sianhu-main` としていた。
- 現在のGitHubリポジトリ `itohen0716/sianhu` に合わせ、接続先を `https://itohen0716.github.io/sianhu/` へ修正。
- 表示選択ポップアップ、自動演奏連携には変更なし。

## v1.2 印刷プレビュー型閲覧
- 閲覧画面を「印刷プレビューに近い譜面閲覧モード」へ変更。
- 文化譜作成アプリの現在の印刷レンダラー／ページ分割を利用。
- 2ページ以上は1ページずつ表示し、［前のページ］［次のページ］とページ番号を表示。
- 1ページだけの場合はページ送りを非表示。
- 左側の「絲庵－Shian－／写譜」は表示しない。
- 上部は［文化譜を見る］と［文化譜面帳へ戻る］の閲覧専用ヘッダー。

## v1.3 閲覧レイアウト修正
- v1.2で印刷CSSが閲覧ヘッダーへ干渉し、文字が縦に崩れる問題を修正。
- 閲覧操作UIと印刷譜面ページを完全分離。
- 印刷ページは専用iframe内だけで印刷CSSを適用。
- ヘッダーは横並び固定：文化譜を見る／前ページ・ページ数・次ページ／文化譜面帳へ戻る。
- A4横相当ページを画面中央へ配置し、画面幅・高さに合わせて等比縮小。
- 2ページ以上のみページ送りを表示。
