# 絲庵 文化譜面帳（新規作成版 v1.6）

既存の文化譜面帳コードを流用せず、0から作り直した最初の段階です。

## 現在実装済み
- トップ画面
- 「＋文化譜を追加」から文化譜JSONを選択
- かな曲名は読みを自動利用
- 漢字を含み読み情報がない場合は、初回だけ「よみ」を入力
- 読みを使った50音順の自動整列
- ［すべて／あ／か／さ／た／な／は／ま／や／ら／わ］絞り込み
- 曲名・よみ検索
- 同名曲の重複時は「更新／キャンセル」
- 譜面帳から削除（元JSONは削除しない）
- ブラウザ localStorage に譜面帳データを保存

## 未実装
- 「譜面を見る」
- 編集連携

未実装ボタンは、現段階では誤動作防止のため無効化しています。

## v2.0 ［譜面を見る］根本修正
- 原因を特定：文化譜アプリ本体には `?scorebook-view=1` を処理する実装が存在しないため、v1.9の直接遷移方式では閲覧モードにならなかった。
- さらに、公開中の文化譜アプリを変更せずに閲覧する方式へ変更。
- 選択譜面を文化譜アプリ本来の保存キーへ一時的に渡し、文化譜アプリ自身の通常 `render()` で描画。
- 描画後は元の編集用localStorageを復元し、閲覧iframeからの保存を遮断。
- 文化譜内部のCSS・幅・歌詞・唄・コメント・書き込み座標は変更しない。
- 完成した `.paper` をiframeごと外側から切り抜き・等比縮小する。
- ［文化譜面帳へ戻る］は常に `./index.html` へ戻るため、写譜ページへ誤遷移しない。

## v2.2 印刷ページ閲覧方式
- v2.1は却下のため使用せず、v2.0から分岐。
- 通常の `.paper` を閲覧用に縮小する方式を廃止。
- 文化譜アプリ自身の印刷処理 `ShianPrintV2.render()` が生成する `#printRootV2 .pv2-page` を閲覧の正本に変更。
- 印刷DOMを別文書へコピーしない。生成された同一文書・同一DOMをそのまま表示する。
- `print-v2.css` の `@media print` 内規則を、同じ文書内の閲覧専用 `body.print-view` スコープへ展開。
- A4印刷ページ単位で表示し、複数ページは前／次で切り替える。
- 編集UI・レイヤーパネルは閲覧ページに含めない。

## v2.3 印刷CSS適用不具合の根本修正
- v2.2の異常表示原因を特定。
- v2.2では `.pv2-` という文字列の出現ごとに `body.print-view` を追加していた。
- その結果、`.pv2-page .pv2-title` などの子孫セレクタが壊れ、譜線・数字・歌詞・注釈等の印刷CSSの大半が適用されていなかった。
- v2.3では文化譜アプリ自身の `@media print` 内CSSを一切書き換えず、そのまま同一文書の画面表示へ適用する。
- `ShianPrintV2.render()` 実行前のiframeは1200pxのPC幅で固定し、写譜画面の実寸取得もPC条件で行う。
- 表示対象は `#printRootV2 .pv2-page` の実物のみ。通常の写譜画面・編集レイヤーは非表示。
- 閲覧終了時に文化譜アプリ本来のlocalStorageを上書きしないよう保存を遮断。


## v2.4 閲覧枠の改善
- 各ページごとに実際の表示領域を再計測し、右端の注釈や下端の要素が切れにくいよう修正。
- ページごとに個別の幅・高さを使って閲覧枠を決定。
- 表示倍率の上限を緩め、余白が大きい画面では譜面を少し大きく表示。
- 右側・下側の安全余白を追加。

## v3.0 ［譜面を見る］再構築
- viewer.html を作り直した。
- 文化譜作成アプリ側では、通常表示・歌詞・コメント・印刷プレビューが正しいことを前提に、その処理を正本として使用。
- 以前の固定1200px描画を廃止し、閲覧開始時の実ブラウザ幅で文化譜作成アプリの通常画面を完全描画。
- フォント・譜面・注釈DOMの寸法が安定するまで待ってから、文化譜アプリ本来の beforeprint → ShianPrintV2.render() を実行。
- コメント・歌詞・奏法・書き込み等の座標は閲覧側で補正・再計算しない。
- 生成された印刷DOMを同一文書内のまま使用し、外側iframeだけを移動・拡大縮小。
- 閲覧倍率は横幅基準。高さに合わせて縮小しないため、譜面を従来より大きく表示し、ページ下端はブラウザ縦スクロールで最後まで表示。
- 各ページの実描画範囲を計測し、右端・下端の安全余白を確保。
- ［文化譜面帳へ戻る］は ./index.html 固定。
