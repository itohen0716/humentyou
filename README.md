# 絲庵 文化譜面帳（新規作成版 v0.7）

既存の文化譜面帳コードを流用せず、0から作り直した最初の段階です。

## 現在実装済み
- トップ画面
- 「＋文化譜を追加」から文化譜JSONを選択
- かな曲名は読みを自動利用
- 漢字を含み読み情報がない場合は、初回だけ「よみ」を入力
- 読みを使った50音順の自動整列
- ［すべて／あ／か／さ／た／な／は／ま／や／ら／わ］絞り込み
- 曲名・よみ検索
- 同名曲の重複時は「更新／キャンセル」
- 譜面帳から削除（元JSONは削除しない）
- ブラウザ localStorage に譜面帳データを保存

## 未実装
- 「譜面を見る」
- 「自動演奏」
- 編集連携

未実装ボタンは、現段階では誤動作防止のため無効化しています。

## GitHub Pages
このフォルダの中身をリポジトリ直下へアップロードすれば、`index.html` がトップページになります。
