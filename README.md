# 文化譜面帳 v6.0

GitHub Pages のトップ `index.html` は「文化譜面帳」です。

構成:
- `/index.html` : 文化譜面帳トップ
- `/editor/index.html` : 三味線文化譜 作成・編集
- `/editor/annotations.html` : 書き込み
- `/auto-player/index.html` : 自動演奏

譜面帳から編集画面を開いた場合:
- 「読込」「＋ 新規作成」はグレーアウトして操作不可
- 「譜面帳から開いているため使用できません」と案内表示
- 上部に「文化譜面帳 / ← 譜面帳に戻る」を表示

譜面帳から自動演奏を開いた場合:
- 「絲庵譜を読み込む」はグレーアウトして操作不可
- 同じ理由案内を表示

各画面は中央配置し、譜面帳経由ヘッダーは各画面本体の表示幅に追従します。
